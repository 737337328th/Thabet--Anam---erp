# اختبار قبول خطة أونكس — ثابت أنعم

يعتبر المسار جاهزًا للعمل الفعلي فقط بعد نجاح البنود التالية:

- [ ] الشركة الصحيحة ظاهرة في ERPNext.
- [ ] العملة الأساسية صحيحة قبل أول قيد فعلي.
- [ ] دليل الحسابات العربي معتمد وأرقامه بدون ترقيم عشري.
- [ ] 1201 Receivable و2101 Payable مضبوطتان كحسابي تحكم.
- [ ] الصندوق والبنك والمحفظة موجودة.
- [ ] طرق الدفع: نقدي، بنك، محفظة إلكترونية، حوالة.
- [ ] مراكز التكلفة الأربعة موجودة.
- [ ] أصناف الخدمات الأربعة مرتبطة بحسابات الإيراد والمصروف ومراكز التكلفة.
- [ ] إنشاء فاتورة خدمات واحدة بدون أخطاء.
- [ ] إنشاء سند قبض مرتبط بفاتورة.
- [ ] إنشاء سند صرف تجريبي.
- [ ] قيد يومية تجريبي متوازن.
- [ ] كشف حساب العميل يطابق الفاتورة والقبض.
- [ ] ميزان المراجعة متوازن.
- [ ] الأرباح والخسائر تعمل.
- [ ] المركز المالي يعمل.
- [ ] صيغة طباعة الفاتورة العربية تعمل.
- [ ] صيغة طباعة سند القبض/الصرف تعمل.
- [ ] النسخ الاحتياطي ينجح قبل اعتماد التشغيل الفعلي.

لا يتم إدخال أرصدة افتتاحية أو إلغاء ترحيل أو حذف قيود مالية تلقائيًا.
