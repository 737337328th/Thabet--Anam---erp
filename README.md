# ثابت أنعم ERP + AI — V4.0

نسخة V4.0 مستقرة للتشغيل التجريبي والاعتماد بعد إكمال إعداد الإنتاج لنظام ثابت أنعم للتخليص الجمركي والمحاسبة، مبنية على FastAPI + SQLAlchemy + PostgreSQL/SQLite + واجهة Web Mobile First.

## جديد V1.7
- صفحة حالة النظام من داخل الواجهة.
- Endpoint لمعلومات الإصدار وقاعدة البيانات وحالة الجاهزية.
- حزمة نشر أوضح للخادم السحابي.
- تدوير النسخ الاحتياطية مع gzip وSHA-256 وحذف النسخ القديمة.
- دليل تشغيل من الجوال.
- استمرار كل وحدات V1.6: الأمان، JWT، سجل التدقيق، PostgreSQL، Docker، النسخ والاستعادة، الصلاحيات، المطابقة، OCR، المحاسبة، التخليص الجمركي، الموافقات.

## ملاحظة مهمة
هذه حزمة تطويرية وليست اعتمادًا نهائيًا للإنتاج. قبل التشغيل الفعلي يجب تغيير بيانات الدخول الافتراضية، ضبط الأسرار، HTTPS، سياسة النسخ خارج الخادم، واختبار الاستعادة.

Current release: V4.0.0
