# ثابت أنعم V4 — Frappe/ERPNext

هذا المستودع هو طبقة تخصيص لمكتب **ثابت أنعم للتخليص الجمركي** فوق ERPNext v16.

## مبدأ التصميم
- ERPNext هو مصدر الحقيقة للمحاسبة، العملاء، الفواتير، المدفوعات والتقارير المالية.
- V4 يضيف ملف التخليص الجمركي والمستورد والبيان وقيد البوابة ووسائل النقل والمستندات.
- لا توجد وظائف قبض/صرف/ترحيل مالي تلقائي داخل V4.
- وظائف الذكاء الاصطناعي المستقبلية تكون للتحليل والمراجعة فقط ما لم يصدر أمر صريح لعملية حساسة.

## التوافق
- Frappe >=16,<17
- ERPNext >=16,<17

## التثبيت
```bash
bench get-app https://github.com/737337328th/Thabet--Anam---erp
bench --site <SITE> install-app thabet_anam_v4
bench --site <SITE> migrate
bench --site <SITE> list-apps
```

## الأمان
V4 لا ينفذ تلقائيًا قبضًا أو صرفًا أو ترحيلًا أو إلغاء ترحيل. العمليات الحساسة تبقى تحت صلاحيات ERPNext وأمر المستخدم الصريح.

## تشغيل مجاني 100%
المسار الموصى به هو التشغيل الذاتي عبر Docker على جهازك:

```bash
bash deploy/free_local/docker_zero_cost.sh
```

تفاصيل التشغيل والنسخ الاحتياطي في `deploy/free_local/README_AR.md`.
هذا المسار لا يشغّل تهيئة مالية أو أرصدة افتتاحية أو ترحيلًا تلقائيًا.
