# قائمة التنفيذ على الموقع

- [ ] Backup قبل أي تغيير.
- [ ] التأكد من اسم الشركة.
- [ ] التأكد من العملة الأساسية.
- [ ] فحص وجود قيود مرحلة قبل استبدال أي دليل.
- [ ] تحميل قالب Chart of Accounts Importer الفعلي.
- [ ] مطابقة دليل الحسابات العربي مع القالب.
- [ ] إنشاء مراكز التكلفة.
- [ ] إنشاء طرق الدفع.
- [ ] إنشاء مجموعة أصناف خدمات ثابت أنعم.
- [ ] إنشاء أصناف الخدمات الأربعة.
- [ ] إنشاء الحقول المخصصة.
- [ ] إنشاء صيغ الطباعة.
- [ ] إنشاء Workspace حسابات ثابت أنعم.
- [ ] إنشاء فاتورة اختبار.
- [ ] إنشاء سند قبض اختبار.
- [ ] مراجعة كشف حساب العميل.
- [ ] مراجعة ميزان المراجعة.
- [ ] مراجعة الأرباح والخسائر.
- [ ] مراجعة المركز المالي.
- [ ] Backup بعد نجاح الاختبار.

لا يبدأ التشغيل الفعلي قبل نجاح الاختبارات السابقة.
